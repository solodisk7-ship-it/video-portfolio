# Сопровождение каталога без CMS

Все операции выполняются в content/works.ts. После правки запускайте
pnpm validate:content, затем pnpm build.

Сейчас работаем локально в режиме demo. Сборка не публикует сайт. Push в GitHub,
deploy и изменения в облаке выполняются только после отдельного согласования.

## Добавить работу

1. Подготовьте slug-v01.mp4 и WebP-обложку.
2. После отдельного согласования загрузите MP4 в Object Storage с Content-Type: video/mp4.
3. Добавьте объект Work; order и slug должны быть уникальными.
4. Для немедленного показа поставьте featured: true. Фиксированного количества нет:
   можно добавить 12-ю и последующие работы без изменения проверок. Минимум одна
   видимая работа должна быть Featured. featured: false оставляет работу для Load More.
5. Добавьте техническую запись в ops/release-manifest.json.

~~~ts
{
  slug: 'project-name',
  title: 'Project Name',
  category: 'Social Campaign',
  role: 'Motion Design',
  year: 2026,
  ratio: '9:16',
  poster: '/works/project-name.webp',
  videoKey: 'videos/project-name-v01.mp4',
  featured: false,
  order: 13,
  visible: true,
}
~~~

Если в ролике есть речь, добавьте captions: '/captions/project-name.en.vtt'.

## Заменить видео

1. Не перезаписывайте существующий объект.
2. Загрузите project-name-v02.mp4.
3. В каталоге измените только videoKey.
4. Обновите manifest и соберите сайт.
5. Старый объект сохраните для отката. Перенос в retired/ и срок удаления
   согласуются отдельно; наличие правила Lifecycle нельзя предполагать.

Так rollback не зависит от кеша и не требует восстановления перезаписанного файла.

## Скрыть, вернуть и изменить порядок

- Скрыть: visible: false. Объект и manifest не удаляйте до завершения периода rollback.
- Вернуть: visible: true, затем проверьте порядок и начальную сетку.
- Поменять порядок: измените уникальные целые order.
- Убрать из Featured: убедитесь, что остаётся хотя бы одна видимая Featured.
- Если скрыта работа, выбранная для предпросмотра ссылки, замените `socialImage`
  в `content/site-config.ts` на обложку другой видимой работы и её размеры.

## Rollback

1. Верните предыдущий videoKey и соответствующую запись manifest.
2. Если объект уже в retired/, скопируйте его обратно в videos/.
3. Соберите и проверьте локальную версию. Публикация в Cloudflare Pages — только
   по отдельному разрешению владельца, не часть текущего demo-наполнения.
4. После разрешённой публикации проверьте /release.json и Range/206.
