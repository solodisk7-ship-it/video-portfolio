# Release QA

Это список проверок, а не заявление, что все пункты уже выполнены.
Для текущего локального demo проверка финального релиза должна оставаться заблокированной.

- На первом экране нет запросов .mp4; видео появляется только после открытия карточки.
- MP4 возвращает Content-Type: video/mp4, Accept-Ranges: bytes и 206 на Range.
- После закрытия или навигации старый video src удалён.
- Retry работает при offline/404/5xx.
- 16:9, 1:1, 4:5, 9:16 показаны без crop и растяжения.
- Все видимые Featured показаны сразу; их количество берётся из каталога.
  Load More добавляет не более 12 оставшихся работ; при их отсутствии кнопки нет.
- Escape закрывает dialog; Tab не выходит из него; фокус возвращается в карточку.
- Arrow Left/Right не перехватываются, когда фокус на native video controls.
- Все интерактивные зоны не меньше 44×44 px, touch и клавиатура работают.
- На 360, 390, 430 px и desktop нет горизонтального scroll.
- Chrome, Edge, Firefox, Safari iOS и Chrome Android проверены вручную.
- Основные локальные UI-тесты: `pnpm test:e2e` (Chromium + мобильная эмуляция).
- Полный набор: установить движки `pnpm exec playwright install chromium firefox webkit`,
  затем `pnpm test:e2e:all`. Workflow CI устанавливает движки и запускает этот же набор
  без публикации сайта. Запуск CI произойдёт лишь после будущей разрешённой отправки кода.
- UI-тесты используют локальный синтетический клип; реальные MP4 проверяются отдельно
  командой `pnpm test:media` (чтение MIME, Range/206 и CORS всех видимых работ).
- UI-тест Retry вызывает событие ошибки и проверяет восстановление элемента/источника.
  Реальное воспроизведение и перемотку также проверять в браузере с поддержкой H.264.
  Подсказка `preload="metadata"` не гарантирует немедленный сетевой запрос во всех движках.
- При открытии мышью и клавиатурой фокус после закрытия возвращается на карточку,
  в том числе в WebKit, где нажатие кнопки мышью может само по себе не фокусировать её.
- Open Graph и Twitter используют `siteConfig.socialImage`, а не скрытую демо-работу.
- Проверка роста: модульные тесты покрывают более 11 Featured и Load More на 30 работах.
- При 200% zoom контент не перекрывается и остаётся доступным.
- WebVTT включается для ролика с речью.
- Lighthouse: LCP ≤ 2.5 s, CLS ≤ 0.1.
- После разрешённой публикации Cloudflare `/release.json` должен содержать опубликованный commit.
