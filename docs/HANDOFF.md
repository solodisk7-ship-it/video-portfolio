## Проверенный локальный запуск

Node 24.12.0, pnpm 10.26.2. Из корня репозитория:

```powershell
pnpm.cmd install --frozen-lockfile
pnpm.cmd quality
pnpm.cmd exec next build --webpack
pnpm.cmd check:export
pnpm.cmd start
```

Адрес: http://127.0.0.1:4173. После сборки: `pnpm.cmd test:e2e`.

Обычный build использует Turbopack: 13.11 он падал локально; проверенная альтернатива — Webpack выше. Причина требует отдельного исправления. `release:prepare` и `deploy:cloudflare` сейчас блокируются demo-режимом и устаревшим manifest; не обходить gate подменой SHA. Предыдущие публикации делались вручную прямым Wrangler deploy после успешной сборки.

При сетевых проверках Node в окружении владельца нужен `NODE_OPTIONS=--use-system-ca`. Firefox/WebKit для полного локального теста надо установить отдельно; их отсутствие в аудите — ограничение проверки, а не установленная несовместимость сайта. CI запускает все четыре проекта браузерных тестов.

Медиа остаются в Yandex Object Storage: portfolio-nonstoplife26-media/videos. Исходные видео, node_modules, out и секреты не входят в передачу через Git. Обложки и маленькая сгенерированная тестовая fixture входят в репозиторий. Доступы к облаку передавать отдельно через приглашения, не через коммиты.
