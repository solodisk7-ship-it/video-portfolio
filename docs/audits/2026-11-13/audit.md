## Замечания и задачи эксперту

### P1. Сохранить полный актуальный исходник и связать релиз с версией

HEAD: `e6cacaed17564f357b0ec72af8149a39a4788f63`, сентябрьский план обслуживания. Изменены 22 отслеживаемых файла; имеются untracked исходники тестов/валидации, fixture и три новые обложки. Список сохранён в диагностике. Обычный clone текущего HEAD не воспроизведёт ноябрьский сайт.

Передавать полную рабочую папку приложения, включая untracked исходники и pnpm-lock.yaml. Перед первым коммитом сделать резервную копию и просмотреть diff; не использовать reset/clean для «очистки». Зафиксировать согласованный baseline отдельным коммитом, не публикуя автоматически без разрешения. Не передавать node_modules, .next, токены, локальные .env или профили Cloudflare/Yandex.

Приёмка: свежий checkout согласованного baseline содержит новые обложки/тесты и воспроизводит каталог; идентификатор сборки можно сопоставить с этим исходником.

### P1. Обновить зависимости и оценить применимость advisories

Полный результат npm/pnpm сохранён в `Дизайн/docs/audits/2026-11-13/dependencies.json`. Три critical относятся к Next.js:

- [next/og ImageResponse](https://github.com/advisories/GHSA-vcvr-r3jv-pc5j): исправление 16.3.6.
- [SVG Image Optimization API](https://github.com/advisories/GHSA-2464-fhr4-w9xw): исправление 16.4.1 для ветки 16.
- [use cache / typed arrays](https://github.com/advisories/GHSA-673q-mjm6-r5xr): исправление 16.4.1.

Эти описания сверены с GitHub Advisory Database. В проверенном коде не найдены next/og, use cache и dangerouslyAllowSVG; публикация статическая и оптимизатор изображений отключён. Поэтому применимость описанных серверных атак к текущей статической публикации не установлена. Это вывод из конфигурации, а не гарантия безопасности. Инструменты разработки и сборки тоже требуют обслуживания.

Эксперту: оценить все пути зависимостей из JSON, выбрать актуальные исправленные совместимые версии, обновить lockfile и повторить проверки. Не ограничиваться только минимальными версиями трёх advisories и не запускать автоматический force-fix без проверки.

### P1. Согласовать реальные правила релиза и обновить manifest/документацию

`contentStatus: demo`, manifest от 15.09, publishedCommit: local-demo. Отсутствуют after-effects-showreel, after-effects-slideshow, urban-vibe. Старая запись shoes-square сохранена, новые v02 не отражены. `deploy:cloudflare` зависит от release:prepare и сейчас не проходит. Фактические публикации выполнялись прямым Wrangler deploy после сборки.

`README.md`, `docs/deployment.md`, часть планов и комментариев всё ещё утверждают «только локальная demo», хотя сайт опубликован. Не менять demo на production только ради зелёной проверки: сначала согласовать смысл режима, обновить manifest и установить единый документированный процесс.

`app/release.json/route.ts` без SOURCE_VERSION/CF_PAGES_COMMIT_SHA создаёт release: local (подтверждено в локальном out). Даже SHA HEAD не идентифицирует незакоммиченный diff. Приёмка: штатная команда релиза проходит по согласованным правилам, manifest отражает реальные версии/хэши/размеры, release.json однозначно идентифицирует опубликованную сборку.

### P2. Восстановить надёжную стандартную сборку

13.11 при замене Urban Vibe Turbopack падал на обработке CSS/запуске дочернего Node, включая запуск вне песочницы. Webpack успешно собрал публикацию. В package.json стандартный build всё ещё использует Turbopack. В текущем аудите повторно проверен именно Webpack, а не исправление Turbopack.

Эксперту: воспроизвести на чистой установке; определить причину либо явно утвердить Webpack как штатный сборщик. Приёмка: документированная команда build работает в Windows и CI из свежего checkout без ручного редактирования зависимостей.

### P2. Завершить кроссбраузерную и публичную проверку

Установить Firefox/WebKit средствами Playwright и повторить все 36 сценариев. CI-файл уже содержит установку браузеров и test:e2e:all, но это локально изменённый workflow; факт его выполнения на GitHub сейчас не проверен. Отдельно проверить Safari/iPhone, Chrome/Android, реальное воспроизведение звука, перемотку и последнюю опубликованную страницу, её CSP/HTTP-заголовки, robots, sitemap, 404 и release.json.

В Windows Node для сетевых проверок потребовалось `$env:NODE_OPTIONS='--use-system-ca'`. Не заменять это отключением проверки TLS. Настройка может зависеть от окружения эксперта.

### P2. Проверить вес новых видео на мобильном интернете

Urban Vibe v02: 15 секунд, 720×1280, около 30 МБ — примерно 16 Мбит/с. В сравнении с предыдущими 20 сек / 20 МБ поток вырос. Это не нарушение формата, но повод сравнить более компактный экспорт на движении/градиентах и медленной сети. Аналогично оценить AE-видео. Не пережимать и не заменять согласованные файлы без просмотра качества владельцем.

### P3. Сделать направление работ явным и улучшить сопровождение

Сейчас direction необязателен; отсутствие значения означает Video Editing. Для нынешних работ это соответствует раскладке, но новая AI/Motion работа без direction молча попадёт не туда. Рекомендуется явное направление для реальных работ и проверка допустимых значений в validate-content. Сохранить All и текущую доступность кнопок (aria-pressed, клавиатура).

Фильтр хранится в состоянии компонента и истории открытого проекта, не в URL: обновление страницы возвращает All, отдельной ссылки на AI Video нет. Это ограничение, не нарушение согласованного сценария. Добавлять глубокие ссылки только при реальной потребности.

CSP содержит unsafe-inline, media-src https:; это широкая политика, но не доказанная уязвимость. Рассмотреть сужение источников после проверки статического Next.js. Наличие nodownload и запрета контекстного меню не предотвращает извлечение публичного MP4.
