# Video portfolio

> Актуальная точка передачи: 13.11.2026. См. [памятку эксперту](docs/HANDOFF.md) и [аудит](docs/audits/2026-11-13/audit.md). Сентябрьские указания ниже о только локальном наполнении исторические; сайт уже опубликован. Любые следующие публикации согласовывать с владельцем.

Статическое англоязычное видеопортфолио на Next.js. Исходный код хранится в
GitHub, а готовая папка `out/` публикуется в Cloudflare Pages. Видео не
запрашиваются до открытия lightbox.

## Локальный запуск

Требуются Node.js 24.12.0 и pnpm 10.26.2.

Текущий этап — локальное наполнение demo. Не выполняйте `git push`, команды
deploy и загрузку новой версии в Cloudflare без отдельного решения владельца:
существующая интеграция GitHub может публиковать каждый push в `main`.

```powershell
corepack enable
corepack prepare pnpm@10.26.2 --activate
pnpm install --frozen-lockfile
pnpm dev
```

Основные проверки:

```powershell
pnpm quality
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
```

Для полного браузерного набора: `pnpm exec playwright install chromium firefox webkit`,
затем `pnpm test:e2e:all`. Интерфейс проверяется на локальной сборке с небольшим
тестовым клипом, без зависимости от доступности облака. Отдельная команда
`pnpm test:media` только читает реальные MP4 и проверяет Range/MIME/CORS.
`pnpm audit:dependencies` проверяет известные уязвимости библиотек через npm.

`pnpm build` создаёт переносимую папку `out/`. Команда
`pnpm release:prepare` дополнительно включает строгий production-gate и
намеренно завершается ошибкой, пока `contentStatus` равен `demo`.
Это ожидаемая защита, а не ошибка локальной сборки. `pnpm build` и `pnpm start`
ничего не публикуют; `pnpm start` открывает локальный сервер на 127.0.0.1:4173.

## Где менять данные

- `content/works.ts` — все работы, их порядок и видимость.
- `content/site-config.ts` — статус demo, публичное имя для SEO, обложка ссылки `socialImage`, адреса и контакты.
- `ops/release-manifest.json` — контрольные суммы и технические параметры видео.
- `public/works/*.webp` — обложки.
- `public/**/*.vtt` — опциональные субтитры.

Инструкции по операциям с работами находятся в
[docs/content-operations.md](docs/content-operations.md), подготовка видео — в
[docs/media-pipeline.md](docs/media-pipeline.md), публикация — в
[docs/deployment.md](docs/deployment.md).

## Текущее состояние

Сейчас каталог имеет статус `demo`, но содержит реальные работы с отдельными
видеофайлами в Object Storage. Каталог продолжает пополняться. Видимые Featured
показываются сразу; их число не ограничено шестью или одиннадцатью. Остальные
видимые работы добавляются кнопкой Load More по 12. Нужны минимум одна видимая
работа и одна видимая Featured, чтобы начальная сетка не была пустой.

Предпросмотр ссылки использует обложку Boots — Horizontal из `socialImage`.
Если эту работу скрывают, нужно выбрать другую видимую работу для обложки.
Смена demo на production, заполнение финального manifest и публикация —
отдельный будущий этап; искусственный минимум 30–50 работ не требуется.

Исходные Word-документы, мастер-видео, исходные PNG, ключи и локальные заметки не
публикуются — они исключены через `.gitignore`.
